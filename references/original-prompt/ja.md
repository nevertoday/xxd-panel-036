# XXD Panel 036 原始プロンプト · 日本語訳

> 閲覧用の忠実な翻訳です。実行時の唯一の基準は[簡体字中国語の原文](zh-CN.md)です。

アップロードした各写真を、それぞれ1枚の独立したハイエンドなデザインポスターにしてください。複数画像を組み合わせず、各写真を個別に出力します。全体は3:4の縦構図を採用し、上下2つの領域の高さは厳密に1:1とし、それぞれ画面の50%を占めます。

上半分には元の写真を残し、被写体のアイデンティティ、構造、姿勢、リアルな質感、自然な光と影、元の色彩の雰囲気を維持し、わずかにハイエンドな写真のカラーグレーディングのみを施して、アート雑誌、インディペンデント出版物、展覧会写真のような質感を持たせます。画面比率に合わせるため、空、地面、または環境の背景を自然に拡張できますが、被写体を引き伸ばしたり、歪めたり、変更したりしてはいけません。

下半分では、写真の中で最も識別性の高い**被写体、輪郭、姿勢、物語上の関係性**を抽出し、その中で最も意味のある感情、動作の方向、空間関係、または隠喩をさらに洗練して、軽やかで、癒やしを感じさせ、抑制の効いたミニマルな連続線の作品として再構成します。写真を機械的になぞるのではなく、ディテールを減らし、繊細で自然かつ手描きのわずかな間を含む線で被写体を再編成します。省略、接続、ずれ、延長、未完成感によって最も重要な識別特徴を残し、少量の線に主要な物語を担わせます。

構図は、**1つの中核的関係、大きな余白、自然に流れる視覚的リズム**を強調します。被写体は中心からずらしたり、トリミングしたり、宙に浮かせたり、自由に展開したりでき、元画像の姿勢と動きの方向に応じて密度と重心を変化させます。人物では互いの関係、動物では動きと生命感、物では重要な構造を強調し、建築物、空間、自然景観では比率、流れ、距離を抽出します。均等な中央配置、複雑な描写、意味のない線は避けます。

背景には、**元画像の色彩と感情から抽出した2–4個の癒やし系の有機的な色域**を加えます。色面は独立した装飾ではなく、被写体の輪郭、動作の方向、ネガティブスペース、視覚的重心に沿って動的に分布させます。一部を被写体の後ろに隠し、一部を端まで延長したり、互いにわずかに重ねて新たな透明の混色を形成したりできます。形はゆるやかで非対称にし、大きさに変化をつけます。縁は規則的なベクター曲線ではなく、わずかな水彩のにじみ、顔料の浸透、不均一な拡散感を持たせ、部分的には明瞭に、部分的には紙の白へ自然に消散させ、色彩が感情のように画面の中をゆっくり流れるようにします。

配色は、**温かみのある紙の白 + 黒灰色の細線 + 低～中彩度で高明度の柔らかな2–4色**を中心にします。固定のパステルカラーパレットを適用するのではなく、上の写真から最も感情的価値と生命力のある色を選び直して調和させます。主要色域、補助色域、ごく小さなアクセントカラーによって面積の階層を構築します。透明な重色は許容しますが、均等な塗り広げ、虹色の配色、重厚な色面、デジタルグラデーションは避けます。

文字にも、線画と一致する**軽やかな手描きの線形言語**を採用します。写真の感情、関係、動作、または隠喩から、ごく短い単語または短句を抽出します。繊細でゆるやか、かつわずかに不規則な筆跡の続け字、単線の手書き文字、または極めて細いエディトリアル書体を使用できます。文字は人物の動作、輪郭曲線、視覚的方向に沿って自然に延長し、1本の線を文字の書き始め、書き終わり、ベースライン、接続線にすることもできます。また、余白の中でわずかに浮遊させたり、曲げたり、被写体に横切らせたりすることもできます。補助的な小文字はごく少なく細く保ち、文字を後から追加した組版モジュールではなく、画面内のもう1種類の線のように見せます。

全体として、**連続する細線、流れる色域、透明な重色、柔らかな余白、手書き文字が互いに呼吸する**視覚的関係を表現し、軽やかで、親密で、癒やしがあり、ロマンチックで、含蓄があり、暮らしの感覚に富んだものにします。最終的な作品は、写真を線画に変換するのではなく、実際の場面を感情の流れを伴う現代的でミニマルな絵本風のエディトリアル作品へと再び抽出したものです。硬質なベクター色面、規則的な円形の斑点、複雑な背景、カートゥーン化、商業書体、テンプレート感は避けます。

# XXD Panel 036｜流动色域连续线条生产提示词

## 运行时完整画布契约（最高优先级）

- `TOP_BOTTOM` 与 `LEFT_RIGHT` 默认把当前原图作为高保真编辑／参考输入，用本提示词一次生成一张完整成品；不要预先拆成摄影半幅和设计半幅。
- 上下模式在整张成品中保留上方约 50% 的高保真原图，在下方完成本风格转译；左右模式对应左侧约 50% 原图与右侧风格转译。两区要在色彩、光线、节奏、文字与含义上形成一体化设计。
- `DESIGN_ONLY` 与 `WALLPAPER_PACK` 使用完整画布，原图只作身份与内容依据而不显示。壁纸仍按设备分别重新构图。
- `FINAL CANVAS` 指整张最终成品比例／像素，必须由用户在生成前明确；不得静默采用源图尺寸。`DESIGN FRAME` 只在完整画布重试失败并触发确定性拼合兜底时使用。
- 完整画布失败时只针对失败条件重试一次；仍失败、用户要求原片逐像素不变、当前通道无法实现目标画幅，或需要无创像素校准时，才允许脚本拼合。

### 模型优先级与凭据

- **优先使用 GPT Image 2。** 当 GPT Image 2 通过当前内置图像工具或已配置兼容通道可用时，先用它完成本提示词要求的高保真垫图／编辑与完整画布生成。
- 也支持 Seedance 5.0 Pro、Nano Banana Pro（Gemini Image Pro）、Nano Banana 2（Gemini Image Flash）或其他兼容位图模型，但只有实际通道具备原图保真、整张成品画幅、目标语言文字，以及连贯壁纸所需多图参考能力时才可使用。
- 备用模型只替换生图通道，不得改变本提示词的模式、画幅、原图可见性、文案、语言、壁纸关系或“完整画布优先、拼合仅兜底”的执行逻辑。不能满足硬性条件时不得静默降级。
- 没有合适通道时，请用户启用生图工具或提供 API Key。用户主动提供凭据可以用于当前任务，但不得在回复、日志或提示词中回显、展示、记录或泄露其值；未经明确要求不得长期保存或修改全局路由配置。
- 按实际生图能力判断可用性，不因某个工具、供应商名称或单一环境变量缺失就武断判定全部通道不可用。

只处理当前新任务明确提供的这一张源照片。私下锁定身份、结构、姿态、方向、动作、功能、开口、关系、情绪含义与源图色彩，至少保留三个源图专属线索；不得借用其他输入、旧输出或样张。

## 审美重构

把源图提炼为一个可识别的核心关系，以少量纤细、自然停顿的连续线重组；再让二至四块源图衍生的透明治愈色域顺着轮廓、动作、负空间与情绪重心流动。

严格遵循这条因果链：锁定身份与关系 → 找到一个情绪或方向命题 → 用稀少连续手绘线重组 → 分布二至四块源图衍生透明有机色域 → 让局部叠色形成克制综合色 → 保住纸白呼吸 → 让目标语言文字成为画中另一根线。

## 硬性视觉要求

- 从轮廓、姿态、方向、动作、开口、距离或关系中保留至少三个源图专属线索。
- 使用黑灰纤细连续线，带自然停顿、轻微手写迟疑、省略、连接、延伸与未完成边缘；不得机械描摹。
- 使用二至四块从源图提炼的低至中饱和、高明度不对称色域；轻微水彩晕染必须顺应主体结构与负空间。
- 保留大面积纸白呼吸；叠色只形成少量透明综合色，不得使用数字渐变、硬矢量色块、规则圆斑、彩虹铺色或厚重填满。
- 只让一个核心关系占主导；位置可依据源图方向偏置、悬置、裁切或轻柔延伸。

## 文案与语言

服从已经确认的自动文案、准确自定义文案或无文字模式，以及目标语言／地区。只用一个与源图强绑定的极短词或短句。采用目标语言中自然的纤细手写或极轻编辑字体，让主体线成为起笔、收笔、基线、连接线或路径；最多增加一条微型辅助信息。 用户准确文案逐字保留；无文字模式不得出现字母、字符、数字、标题、标签或伪文字。

## 模式与验收


拒绝：机械描摹、装饰性一笔画图标、硬矢量色块、规则圆斑、数字渐变、固定粉彩卡、彩虹色、密集场景、卡通化、商业字体与模板排版。同时拒绝 logo、水印、色卡、UI、设备样机、无依据事实、伪外语和不可读文案。

任何硬性条件失败都必须纠正位图资产，不得以程序绘图、SVG、HTML、Canvas、3D 代码或后期文字覆盖伪造成品。
